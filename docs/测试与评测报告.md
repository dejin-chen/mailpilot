## 2. 自动化测试

最终实战验收及运行时故障修复结果为 `278 passed in 20.95s`。新增测试验证：模型第一次返回无效结构化结果时会有限重试并累计全部 Token；Graph 终态无论从 Checkpointer 恢复为枚举还是字符串，都不会把失败、忽略或非终态映射错误；长期记忆 Store 操作受有限超时保护，主 Session 失效时会用新 Session 兜底写入失败终态；Checkpointer 能安全恢复 `MemoryType`；轨迹页会合并 SSE 增量事件并在终态自动刷新；Nginx upstream 必须启用 Docker DNS 动态解析。

覆盖：

- Service 单元测试。
- Schema 和安全 Policy。
- Repository/真实 PostgreSQL。
- Redis 登录限流与写锁。
- MCP 工具合同、客户端和 Streamable HTTP。
- LangGraph 节点、路由、Checkpoint。
- 审批暂停、接受、拒绝、修改、反馈和恢复。
- 写操作幂等与结果未知。
- 长期记忆隔离、同步、版本和删除。
- FastAPI 权限和统一异常。
- SSE 增量与断线恢复。
- Langfuse No-op、适配器和脱敏。
- 评测数据、指标和运行器。
- 生产环境预检和 Nginx 公共入口验收逻辑。

普通 pytest 不调用真实模型，不消耗模型额度。

## 7. 指标边界

- 不把 Fake 100% 写成模型成绩。
- 不用 LLM Judge 代替权限、幂等和审批测试。
- 不删除预期失败案例来提高工具成功率。
- 不虚构并发量、可用性或节省工时。
- 真实模型结果必须注明模型版本、数据版本、样本量和日期。
